# Источник и локальные изменения

В `vendor/mippia/` находятся исходные файлы проекта
[Mippia/Music-Plagiarism-Detection](https://github.com/Mippia/Music-Plagiarism-Detection),
авторы Seonghyeon Go и Yumin Kim, MIPPIA Inc.
Зафиксирован commit `109c703242546e88914d8dbf04311e06bc3113cb`.
Исходный README сохранён. В нём авторы объявляют GPL со ссылкой на GPLv3;
текст GPLv3 включён в `LICENSE`. Адаптер, CLI и тесты также предоставляются под GPLv3.
Для вложенного Beat Transformer сохранён его MIT LICENSE (Zhao Jingwei, 2022).

`UPSTREAM.json` содержит исходные SHA-256, хеши изменённых файлов и двух checkpoint.
Сравнение фрагментов выполняет оригинальная функция
`compare.calculate_metric_optimized`, а построение признаков — функции
`compare_utils`; алгоритм не заменён другой метрикой.

Изменённые исходные файлы Mippia (22 октября 2026):

- `segment_transcription.py`: выбор CPU/CUDA через `MIPPIA_DEVICE`;
  Demucs получает тот же device, отключено случайное усреднение сдвигов,
  обработка разбита на короткие окна для ограничения памяти (по умолчанию 2 с,
  параметр CLI `--separation-segment`). Это может влиять на качество разделения.
  Ограничивается также `submodel.segment`: Demucs 4.0.1 иначе дополняет
  короткие окна до обучающей длины 7.8 с и не уменьшает пик памяти.
- `wav_quantizer.py`: путь checkpoint относительно файла модуля,
  загрузка на выбранное устройство с `weights_only=True`, inference mode,
  понятная ошибка при недостатке долей/сильных долей.
- `ml_models/AST/do_everything.py`: абсолютный путь checkpoint относительно модуля.
- `ml_models/AST/predictor.py`: `weights_only=True`, уменьшен batch до 32;
  его можно задать через `MIPPIA_AST_BATCH_SIZE`.
- `compare.py`: в исходной ветке без нот возвращается пустой список вместо
  кортежа несовместимого с исходным форматтером. CLI использует собственную
  обработку пустых сегментов и напрямую вызывает оригинальную метрику.

Адаптер читает обычный JSON, ограничивает размер батчей сравнения,
отбрасывает окна за концом записи и пустые/слишком короткие последовательности нот.
Поддерживается размер 4/4: исходный comparator использует фиксированную сетку
48 шагов на такт. Схожесть октав сохраняется из chroma-представления;
перебор всех транспозиций по полутонам не добавлен.

Большие checkpoint не коммитятся: команда `weights` получает именно
зафиксированные исходные файлы и проверяет размер и SHA-256.
Demucs при первом распознавании отдельно загружает свои pretrained-модели.
Каталоги Covers80, SMP и пользовательское аудио не включены в исходники программы.
Синтетические примеры созданы для технической проверки и не являются
доказательством точности алгоритма на реальной музыке.

Условия на веса и данные отличаются от лицензий исходного кода.
У madmom код BSD, модели/данные CC-BY-NC-SA-4.0; здесь используются его
DBN-процессоры с выходом Beat Transformer. Программа предназначена для
личной проверки модуля; она не предоставляет права на чужие музыкальные записи.

Архив исходников madmom не включает Git-submodule `madmom/models`, но Python
пакет требует его инициализатор при импорте. В `vendor/madmom_models` сохранены
только оригинальные `__init__.py` и LICENSE из
[CPJKU/madmom_models](https://github.com/CPJKU/madmom_models/tree/7e3dc1b0cad499792767074d03c38b194b9b0a79),
commit `7e3dc1b0cad499792767074d03c38b194b9b0a79`,
авторы Department of Computational Perception, JKU Linz / OFAI.
Эти два файла имеют отдельную лицензию CC-BY-NC-SA-4.0, сохранённую рядом;
GPL-объявление адаптера их не перелицензирует. `install_madmom_metadata.py`
добавляет их в отдельное окружение, если они отсутствуют.
Предобученные модели madmom при этом не скачиваются.
